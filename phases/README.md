# Omnivra 16-Phase Engineering Roadmap

Omnivra executes in 16 structured, sequential phases (Phase 00 through Phase 15).

| Phase | Name | Focus |
| ----- | ---- | ----- |
| [Phase 00](phase-00-discovery.md) | Discovery & Vision | Problem formulation, user personas, interaction models |
| [Phase 01](phase-01-foundation.md) | Repository Foundation | Monorepo scaffolding, ADRs, AI agents & skills |
| [Phase 02](phase-02-core.md) | Core Event Bus & Types | Strongly typed event loop, envelope schema, pub/sub |
| [Phase 03](phase-03-rules-actions.md) | Rules & Action Engine | Predicate evaluation, condition matrix, action dispatcher |
| [Phase 04](phase-04-browser.md) | Browser Extension Host | WebExtension MV3, WXT shell, content scripts |
| [Phase 05](phase-05-voice.md) | Voice Engine | WebSpeech API, Whisper integration, wake-words |
| [Phase 06](phase-06-gesture.md) | Gesture Engine | MediaPipe Hands, landmark classification, FPS throttling |
| [Phase 07](phase-07-eye-face.md) | Eye & Face Engine | Iris tracking, blink detection, head tilt, 9-point calibration |
| [Phase 08](phase-08-vscode.md) | VS Code Extension Host | Command bridge, active editor context, split navigation |
| [Phase 09](phase-09-ai.md) | AI Provider Gateway | Local Ollama, Gemini, Claude, NL-to-rule compilation |
| [Phase 10](phase-10-plugin-sdk.md) | Plugin SDK & Runtime | Sandboxing, capability manifests, third-party hooks |
| [Phase 11](phase-11-desktop.md) | Desktop Companion | Tauri v2, Rust IPC, native messaging, global shortcuts |
| [Phase 12](phase-12-cloud.md) | E2EE Cloud Sync | Zero-knowledge WebSocket relay, CRDT rule synchronization |
| [Phase 13](phase-13-marketplace.md) | Community Marketplace | Plugin discovery, verified signing, one-click installation |
| [Phase 14](phase-14-hardening.md) | Hardening & Audits | Security penetration testing, WCAG AA, FPS benchmarks |
| [Phase 15](phase-15-release.md) | General Availability (v1.0) | Multi-store deployment (Chrome, Firefox, VS Code, Tauri) |
