# Target User Personas

## Persona 1: The High-Velocity Developer (Alex)
* **Profile**: Senior Full-Stack Engineer working in VS Code and dual monitors.
* **Pain Point**: Constant context-switching between code, terminal, documentation tabs, and music playback triggers wrist fatigue.
* **Omnivra Usage**: Uses subtle hand raises to toggle terminal, gaze tracking to switch active editor splits, and voice whispers to trigger test runs.

## Persona 2: The Assistive Accessibility User (Maya)
* **Profile**: Software engineer and student with limited upper-limb mobility.
* **Pain Point**: Standard keyboard navigation is fatiguing and slow; existing eye-trackers require expensive $1,000+ specialized hardware.
* **Omnivra Usage**: Uses standard laptop webcam for high-precision eye tracking and blink triggers paired with voice commands for full hands-free computing.

## Persona 3: The Content Creator & Live Streamer (Devon)
* **Profile**: Tech streamer and educator demonstrating live code.
* **Pain Point**: Managing OBS scenes, YouTube chat, and IDE zoom while keeping hands on the demo is awkward.
* **Omnivra Usage**: Uses distinct hand gestures (e.g. palm up for scene switch, peace sign for code zoom) to automate streaming workflows hands-free.
