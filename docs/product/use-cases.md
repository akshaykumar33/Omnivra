# Key Use Cases & Interaction Scenarios

## UC-01: Hands-Free Media Scrubbing while Coding

- **Trigger**: Candidate is reviewing a technical tutorial on YouTube while coding in VS Code.
- **Input**: Double blink or palm-up gesture.
- **Context**: YouTube tab running in background or split window.
- **Action**: Pause/Resume video or adjust playback speed without defocusing the editor.

## UC-02: Rapid Split Navigation via Gaze

- **Trigger**: Looking at the secondary VS Code editor split while pressing hotkey or voice whisper "here".
- **Input**: Eye gaze coordinates + discrete trigger.
- **Context**: VS Code active window.
- **Action**: Move cursor focus immediately to the looked-at pane.

## UC-03: Natural Language Context Switching

- **Trigger**: Vocalizing "Focus mode".
- **Input**: Speech recognition intent match.
- **Context**: System wide.
- **Action**: Minimizes messaging apps, launches project workspace in VS Code, opens Linear tickets in browser.
