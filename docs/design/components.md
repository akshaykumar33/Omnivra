# UI Components Taxonomy

1. **Primitives**: `Button`, `Input`, `Select`, `Switch`, `Dialog`, `Popover`, `Tooltip`, `Badge`, `Slider`.
2. **Domain Components**:
   * `GestureVisualizer`: Live 21-landmark hand wireframe preview.
   * `ConfidenceMeter`: Real-time signal strength bar.
   * `RuleCard`: Expandable trigger-action card with enable toggle.
   * `CalibrationTarget`: 9-point animated gaze calibration dot.
   * `PermissionShield`: Visual badge showing granted capability scopes.
