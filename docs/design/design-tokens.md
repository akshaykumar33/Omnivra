# Design Tokens & CSS Variables

| Token | Dark Mode Default | Light Mode Default | Semantic Purpose |
| ----- | ----------------- | ------------------ | ---------------- |
| `--bg-base` | `#0a0d14` | `#ffffff` | Canvas background |
| `--bg-surface` | `#101522` | `#f8fafc` | Card / container background |
| `--bg-raised` | `#182032` | `#f1f5f9` | Modals, popovers, dropdowns |
| `--border-subtle` | `#1e293b` | `#e2e8f0` | Dividers and inactive borders |
| `--border-focus` | `#0284c7` | `#0284c7` | Active input highlight |
| `--text-primary` | `#f8fafc` | `#0f172a` | Primary headings & body |
| `--text-muted` | `#94a3b8` | `#64748b` | Secondary labels & metadata |
| `--accent-primary` | `#38bdf8` | `#0284c7` | Primary interactive brand color |
| `--status-active` | `#10b981` | `#059669` | Active camera / tracking status |
| `--status-warning` | `#f59e0b` | `#d97706` | Low confidence / warning state |
| `--status-danger` | `#ef4444` | `#dc2626` | Error / permission denied |
