# Typography System

* **Primary Sans Stack**: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
* **Mono / Technical Stack**: `JetBrains Mono, "Fira Code", monospace`

## Scale
* `display`: 32px / 1.2 / 700
* `heading`: 20px / 1.3 / 600
* `subheading`: 16px / 1.4 / 600
* `body`: 14px / 1.5 / 400
* `caption`: 12px / 1.4 / 500
* `code`: 13px / 1.4 / 400
