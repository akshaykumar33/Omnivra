# Design Philosophy — Omnivra

Omnivra UI is technical, calm, fast, dense, and human. We draw inspiration from Linear, Raycast, and Stripe.

---

## 1. Tenets

- **Calm & Focused**: Avoid visual clutter. High contrast and clean dark/light modes.
- **Information Density**: Dense status indicators, live gesture confidence meters, and compact rule editors.
- **Purposeful Motion**: Micro-interactions under 150ms. Never block user flow.
- **Non-Intrusive HUD**: Visual overlays must never obscure primary working content.
